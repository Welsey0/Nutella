# Nutella Flyby
Make the famous [Artemis II Nutella jar](https://www.youtube.com/watch?v=J6FwPOb_Q_M) show up on any web page! Incredible marketing. Great job Nutella. /j

Copy the code from nutella.js.bookmarklet into a bookmark in your bookmark bar to gain the ability to summon the Nutella whenever neccesarry!
